# RE:HACK - ACM MPSTME Hackathon Prototype

## 🚀 Overview
This repository contains the frontend prototype for the "24-Hour Reverse Engineering Hackathon," developed as a task for the ACM MPSTME Tech Committee selection process.

## 🏗️ Architecture & Features
Instead of a single static page, this project features a multi-page interactive flow to demonstrate complete user journey mapping:
* **`index.html`:** The primary landing page featuring a countdown timer, event schedule, problem statement, and prize tiers.
* **`register.html`:** A functional registration portal featuring dynamic DOM manipulation (form fields for members 3 and 4 appear conditionally based on the selected team size).

## 🎨 UI/UX & Design Philosophy
The design language directly aligns with ACM's modern, technical, and minimalistic identity.
* **Theme:** "Hacker/Tech" dark mode to suit the "Reverse Engineering" concept.
* **Typography:** `Inter` for general readability and `Fira Code` (monospace) for technical accents.
* **Responsiveness:** Built using a mobile-first approach ensuring a seamless experience across desktop, tablet, and mobile breakpoints (including a fully functional mobile hamburger menu).
* **Performance:** Developed via pure HTML5, Vanilla JS, and Tailwind CSS via CDN. Bypassing heavy JS frameworks ensures a blazing fast Time-To-Interactive (TTI) and zero build-step complexity.

## 🛠️ Tech Stack
* **Markup:** Semantic HTML5
* **Styling:** Tailwind CSS
* **Interactivity:** Vanilla JavaScript

## 💻 Local Execution
1. Clone this repository.
2. Open `index.html` in any modern web browser.
3. No `npm install`, node modules, or local server required!
